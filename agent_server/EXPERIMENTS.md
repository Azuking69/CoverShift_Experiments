# 実験項目（2つのリポジトリで共通。内容を変えないこと）
同じ仕事（solver → explain → 承認待ち → 確定）を、同じ項目で試し、結果を RESULTS.md に書く。
| # | 項目 | 見ること | 期待（公式資料より） |
|---|---|---|---|
| E1 | 承認待ち→再開 | 承認待ちで止まり、再開で確定まで進むか。却下で計算に戻るか | AgentServer: 確認済み / AgentCore: 未確認 |
| E2 | 途中でプロセスを落とす | 計算中・承認待ちで落とした後、続きから再開できるか（本番相当の保存先で） | AgentServer: PostgreSQL / AgentCore: Memory |
| E3 | 同じ案件の同時実行 | 同じthread/sessionに2本同時に流したとき、どうなるか | AgentServer: 標準で1本ずつ / AgentCore: わからない |
| E4 | 送信内容 | Claudeへ送る本文に、ダミーの実名が含まれないか（通常経路・エラー経路） | コード側の仮名化で守る |
| E5 | 費用の目安 | 実験で使った時間・量（わかる範囲で） | 参考 |
ダミーの実名：山田太郎・佐藤花子（graph.py の raw_input_names）。送信ログ outbound.log に出てはいけない。
